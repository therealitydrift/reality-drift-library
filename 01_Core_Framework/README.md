# Core Framework

This directory contains the primary canonical materials for the Reality Drift framework. Together, these documents define the framework’s current concepts, terminology, system architecture, visual models, and provenance record.

The core framework describes how systems can remain operational and internally coherent while the representations guiding them progressively lose corrective contact with the realities they are meant to track, describe, govern, or serve. The materials in this directory provide the main reference layer for that work.

---

## Directory Structure

### 01_Overview_and_Definition

Entry-point documents introducing Reality Drift, including the canonical definition, overview materials, and explanatory references for readers approaching the framework for the first time.

### 02_Concept_Papers

Canonical concept papers defining the framework’s major concepts and clarifying their roles, boundaries, and relationships within the larger Reality Drift architecture.

### 03_Glossary

Reference terminology for the Reality Drift framework, including canonical definitions for concepts related to representation, grounding, optimization, correction, cognition, meaning, provenance, and drift.

### 04_System_Architecture

Structural documents describing how Reality Drift develops across representational systems, including the Representation Stack, recursive drift, proxy optimization, feedback weakening, constraint loss, and related system models.

### 05_Diagrams

Reference diagrams and conceptual maps illustrating the framework’s major structures, mechanisms, relationships, and diagnostic patterns.

### 06_Provenance

Records documenting the development, authorship, chronology, canonical status, corrections, and supersession history of the Reality Drift framework.

---

## Purpose

The materials in this directory represent the current canonical reference set for the Reality Drift framework. They are intended to provide a stable conceptual foundation for the broader project while preserving a clear distinction between current canonical material, supporting architecture, and the historical development of the framework.

For a navigable overview of the wider project, including research collections, essays, repositories, and archival mirrors, see the Reality Drift Master Index.
