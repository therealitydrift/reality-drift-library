# Core Framework

This directory contains the primary canonical materials for the Reality Drift framework.

These documents define the framework's core concepts, terminology, system architecture, and supporting visual models. Together they provide the conceptual foundation for the broader Reality Drift project.

---

## Directory Structure

### 01_Overview_and_Definition

Entry-point documents introducing the framework, including the canonical definition, overview, and frequently asked questions.

### 02_Concept_Papers

Formal concept papers describing the framework's major concepts and their relationships.

### 03_Glossary

Canonical terminology and reference definitions used throughout the Reality Drift framework.

### 04_System_Architecture

Structural documents describing the framework's underlying architecture, including the Representation Stack and related system models.

### 05_Diagrams

Reference diagrams and conceptual maps illustrating the framework's major structures and relationships.

---

## Purpose

The materials in this directory represent the current canonical reference set for the Reality Drift framework. They are intended to provide a stable conceptual foundation while remaining accessible to readers approaching the framework for the first time.
