# Visual Reference Guides

This directory contains visual reference guides for key concepts within the Reality Drift framework.

These documents use diagrams, comparisons, and simplified visual models to explain core ideas in a concise, accessible format. They are intended as companion references to the concept papers rather than comprehensive theoretical treatments.

---

## Included Guides

### Optimization Trap vs. Goodhart's Law

Compares the Optimization Trap with Goodhart's Law, highlighting where the concepts overlap and where the Reality Drift framework extends beyond metric optimization.

### Filter Fatigue vs. Information Overload

Distinguishes Filter Fatigue from Information Overload by showing how continual filtering and mediated choice create a different form of cognitive burden.

### Synthetic Realness

A visual guide explaining how optimization, repetition, and mediation can produce environments that appear authentic while gradually becoming detached from direct experience.

### Optimization Trap

A visual overview of how optimization shifts from supporting goals to replacing them, illustrating the structural dynamics of the Optimization Trap.

---

## Purpose

These visual guides provide quick reference materials for readers who want an accessible introduction to key concepts before exploring the accompanying concept papers.
